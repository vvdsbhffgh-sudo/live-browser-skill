# Atlas logos

## Official logo — logo #1, globe meridian (Audiowide wordmark)

**`atlas-official-logo.svg`** — globe with meridian lines, blue gradient
#062A4E → #2F80ED, ATLAS wordmark in **Audiowide** (the gaming-style font the
user chose, 2nd option). `atlas-official-logo-dark.svg` is the dark-background
variant (white wordmark). `atlas-app-icon.svg` is the rounded-square app icon
(gradient tile, white globe, no wordmark).
