How this dashboard works

Same server, same port: this page is served by Atlas at /dashboard. It reads /status and the live event stream /events (SSE). Pause stops the agent so you can take over; Resume lets it continue; Approve allows sensitive actions (delete / send / publish) for this session only — click again to revoke; Record starts/stops saving the session locally.

Atlas never pays. Checkout pages and card numbers are blocked in code. Google sign-in is manual, once, by you, with a dedicated account.

Endpoints: /status · /latest.png · /events · MCP: /mcp · Live View: /

Install as an app: use your browser's "Install" / "Add to Home screen" — Atlas ships a PWA manifest + service worker.
